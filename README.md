# 視覺導向機械手臂撞球系統

這是一個結合電腦視覺、幾何規劃與機械手臂控制的專案，目標是讓機器手臂能夠根據桌面狀態自動判斷擊球點與角度，並完成實際撞球動作。

## 專案簡介

本專案整合了以下技術：
- 電腦視覺辨識桌面與球體
- YOLO 物件偵測
- 幾何計算擊球目標點與擊球角度
- HIWIN 機械手臂控制
- socket 通訊串接視覺端與控制端
- 硬體觸發流程進行實際執行

系統會先透過相機辨識母球、子球、袋口與桌面資訊，再計算符合幾何條件的擊球點與角度，最後將目標資訊透過 socket 傳送給機械手臂控制端，讓手臂移動並完成擊球。

## 專案背景

這個專案源自參加 HIWIN 機械手臂競賽的撞球項目，目標是建立一套可以從影像中感知桌面狀態，並轉成手臂可執行的運動路徑的系統。它涵蓋了目標偵測、軌跡規劃、機械手臂控制與系統整合等多個層面。

## 主要功能

- RealSense 相機擷取桌面影像
- YOLO 模型識別母球、子球與球袋位置
- 計算擊球目標點與擊球角度
- 利用 HIWIN SDK 控制機械手臂執行動作
- Python 視覺端與 C++ 控制端透過 socket 通訊
- 硬體觸發流程協調整個執行序列
- 將相機、辨識、機器手臂與參數設定分離，便於調整與展示

## 執行流程

1. 相機擷取桌面場景。
2. YOLO 辨識母球、子球與球袋位置。
3. 系統估計目標球並計算最佳擊點與擊球角度。
4. 將目標資訊透過 socket 傳送給機械手臂控制端。
5. 控制端接收訊息後進行可到達路徑規劃。
6. 手臂移動至計算位置並執行擊球。
7. 等待硬體確認後進入下一輪循環。

## 解決的挑戰

- 在不同桌面幾何與光線條件下維持穩定的偵測
- 將 2D 影像座標映射到機械手臂可執行的工作空間
- 確保目標點與路徑具有可達性與安全性
- 視覺端與控制端之間的即時通訊
- 將桌面座標與機器手臂座標系統進行校正
